# App icon / logo

Single source of truth: `assets/letters.png`.

## Replacing the icon

1. Overwrite `assets/letters.png`
2. `bun run icons`          — regenerate `assets/icon.iconset/*` (macOS app icon)
3. `bun run build:view`     — re-bundle the in-app rail logo

## Consumers

- `assets/letters.png` — Linux/Windows app icon (`electrobun.config.ts`) and the in-app rail logo (`src/mainview/components/AppRail.tsx`, imported directly from this single source)
- `assets/icon.iconset/*` — macOS app icon; generated by `scripts/gen-icons.sh`, do not edit by hand
