# App icon / logo

Single source of truth: `assets/milu.png`.

## Replacing the icon

1. Overwrite `assets/milu.png`
2. `bun run icons` — regenerate `assets/icon.iconset/*` (macOS app icon)
3. `bun run build:view` — re-bundle the view (the README hero picks the file up directly, no build needed)

## Consumers

- `assets/milu.png` — macOS/Linux/Windows app icon (`electrobun.config.ts`), and the README hero. One file, every size: it is drawn icon-first (stroke ≥ 7% of the mark) so 16px and 1024px read the same mark — see `DESIGN.md` §11.
- `assets/icon.iconset/*` — macOS app icon; generated by `scripts/gen-icons.sh`, do not edit by hand
